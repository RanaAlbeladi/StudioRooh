# Studio Rooh Kids — النسخة الأولى

هذه أول نسخة Development للواجهة الرئيسية، مبنية بـ Next.js + TypeScript ومجهزة لتكون Responsive على الجوال والآيباد واللابتوب.

## ما هو جاهز الآن؟
- Header responsive + قائمة للجوال.
- Hero section بنفس اتجاه الهوية المتفق عليها.
- الثلاث مربعات الأساسية بالترتيب: استكشف الثيمات → اختر الباقة → احجز موعدك.
- على الجوال تظهر الصفحة الرئيسية مختصرة: Hero + الثلاث مربعات + Footer فقط.
- على اللابتوب والآيباد تظهر أقسام الثيمات والباقات في الصفحة الرئيسية.
- بيانات الباقات الحقيقية الحالية: 385 و580 ريال، 3 و4 ثيمات، 10 و25 صورة معدلة.
- عربون افتراضي 100 ريال لكل باقة، ورسوم تأجيل افتراضية 50 ريال داخل ملف البيانات.
- هيكل جاهز لإضافة صفحات الحجز والثيمات والباقات لاحقًا.

## ملاحظة مهمة عن الثيمات
الملف المرسل لا يحتوي أسماء وصور الثيمات الفعلية، لذلك وضعت 4 عناصر مؤقتة فقط. فور إرسال أسماء الثيمات وصورها يتم استبدالها من `data/content.ts` بدون تغيير التصميم.

## تشغيله بدون تحميل برامج على جهازك
سنرفعه في الخطوة التالية إلى GitHub من المتصفح ثم نربطه بـ Vercel. بعد ذلك أي تعديل سيكون من المتصفح، ولا تحتاجين تثبيت VS Code أو Node.js محليًا.
